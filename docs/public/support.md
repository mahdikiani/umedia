# Support and funding

## Get help

Open a [GitHub Issue](https://github.com/mahdikiani/umedia/issues) for bugs and product questions. Include your UMedia version or commit, deployment shape, provider type, steps to reproduce, and redacted logs. The issue form reminds reporters not to include credentials. There is no published response-time guarantee yet.

For direct contact, email [mahdikiany@gmail.com](mailto:mahdikiany@gmail.com) or Telegram [@mahdikiani](https://t.me/mahdikiani). Do not send secrets or private files through either channel.

## Support development

UMedia is free and MIT-licensed. A public donation destination has not been configured yet. GitHub Sponsors will be linked here if the maintainer can receive payouts through the program; otherwise a dedicated donation wallet will be published after it is set up. Until then, reporting bugs, improving docs, and contributing code are useful ways to help.

See [the maintainer's other projects on PyPI](https://pypi.org/user/mahdikiani/), including `usso` and `fastapi-mongo-base`. Those are separate packages and are not UMedia features.
