# Your files, in one self-hosted library.

UMedia brings files from local storage, S3-compatible services, cloud drives, and Telegram into one place you control. Open source, built to run with Docker Compose.

<div class="hero-actions">
  <a href="getting-started/">Read the self-hosting guide</a>
  <a href="https://github.com/mahdikiani/umedia">Explore the source</a>
</div>

</div>

!!! warning "Early beta"
    UMedia is under active development. Provider integrations have different verification levels; review the [provider status](providers.md) and keep independent backups before using important data.

<div class="feature-grid" markdown>

<div class="feature-card" markdown>

### One library

Browse and organize files from configured storage connections through one web interface.

</div>

<div class="feature-card" markdown>

### Your infrastructure

Run the API, web app, and SQLite database in your own Docker Compose environment.

</div>

<div class="feature-card" markdown>

### Cross-provider transfers

Copy and move files between configured providers, subject to the capabilities of each provider.

</div>

<div class="feature-card" markdown>

### Provider adapters

Connect local storage and S3-compatible storage, with beta integrations for selected cloud drives and Telegram.

</div>

## Get involved

- **Try it:** follow [Getting Started](getting-started.md). The checked-in Compose file currently expects an existing Traefik setup.
- **Report a bug or ask for help:** [open a GitHub Issue](https://github.com/mahdikiani/umedia/issues).
- **Contribute:** read the [contributor guide](contributing.md).
- **Support development:** see [support and funding](support.md); a donation destination has not been configured yet.

The current hosted instance at [umedia.uln.me](https://umedia.uln.me) is a maintainer preview and does not offer public account signup.
