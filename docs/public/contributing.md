# Contributing

Contributions are welcome. Start with the root [CONTRIBUTING.md](https://github.com/mahdikiani/umedia/blob/main/CONTRIBUTING.md) and review the current architecture docs before changing provider or library behavior.

## Before opening a pull request

1. Search existing issues and pull requests for related work.
2. Explain the user problem and the intended behavior.
3. Add or update tests for behavior changes; provider contract changes need coverage for every affected adapter.
4. Run the checks relevant to the changed area and report exact commands and results.
5. Update the public docs when a user-facing behavior or provider limitation changes.

For bugs, use the issue form and include the UMedia commit or image tag, provider type, expected behavior, actual behavior, and minimal reproduction steps. Redact credentials and personal data.
