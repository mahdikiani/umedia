# Development Instructions


You are implementing Universal Data Layer.


Rules:

1. Do not tightly couple core with providers.
2. Every external service must be implemented as a provider plugin.
3. Prefer simple extensible design.
4. Avoid premature optimization.
5. Keep interfaces stable.
6. Write tests for provider contracts.
7. Document architectural decisions.


Before implementing large changes:

- explain architecture impact
- identify tradeoffs
- propose alternatives
